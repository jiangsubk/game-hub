Desktop Build

俄罗斯方块 · 桌面版 Python 3 + Pygame 原生实现 · 原 jiangsubk/tetris 仓库

这是三个仓库合并时的第三个 —— 一个跑在本地的 Pygame 版本。 它和网页版玩法同源，但运行在 Python 进程里，有自己的窗口和帧循环。

⚠️
这个版本不能在浏览器里直接玩。

它依赖 Pygame（底层是 SDL）来创建原生窗口和接管输入，浏览器跑不了 Python。 要么装 Python 在本地运行，要么玩 网页版。 源码已完整保留在项目 legacy/tetris.py。

运行方式

powershell
# 安装依赖（只有 pygame 一个）
PS> pip install -r requirements.txt

# 启动
PS> python tetris.py

# 或者一步到位
PS> pip install pygame && python tetris.py

操作

按键功能
← →左右移动
↑旋转
↓加速下落
空格直接落底
C暂存 Hold
P暂停
R重新开始
ESC退出（Web 版没有）

特性

  • 7-bag 随机生成，保证出块公平
  • 影子方块（Ghost Piece）预测落点
  • Hold 暂存，每轮限用一次
  • 墙踢（Wall Kick）旋转不卡死
  • NES 风格计分：100 / 300 / 500 / 800 × 等级
  • 每消 10 行升一级，下落间隔递减

与网页版的差异

运行环境Python 3 + Pygame / 浏览器
渲染方式SDL 原生窗口 / Canvas 2D
计分规则NES 风格（两版一致）
下落间隔下限100 ms / 80 ms
触屏支持无 / 有
最高分存档无 / localStorage
